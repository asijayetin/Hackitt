# Hackitt

Hackitt is a skill-based team formation tool designed for hackathons.

The main goal of Hackitt is to create balanced teams by distributing students based on their skills such as frontend, backend, design, database, AI/ML and other technical skills.

## Current Features

- Landing page
- Student and Organizer signup
- Login system
- LocalStorage based authentication
- JSON based user data
- Student dashboard
- Student profile page
- Organizer profile page

## Phase 1

The first phase of the project will use:

- HTML
- CSS
- JavaScript
- LocalStorage
- JSON

Planned Phase 1 features:

- Skill selection
- Skill validation
- Participant management
- Automatic team generation
- Greedy team balancing algorithm
- Team cards
- Re-shuffle teams
- Manual participant management
- Team balance score

## Phase 2

The second phase will convert the project into a full-stack application using:

- React
- Node.js
- Express.js
- MongoDB
- JWT Authentication

Planned Phase 2 features:

- Organizer dashboard
- Server-side team generation
- Re-shuffle teams
- Manual drag and drop team changes
- MongoDB database
- Organizer-only authorization

## Project Goal

Hackitt aims to help hackathon organizers automatically create balanced teams by distributing participants across different teams according to their skill sets.

## Team

This project is being developed as a group hackathon project.
